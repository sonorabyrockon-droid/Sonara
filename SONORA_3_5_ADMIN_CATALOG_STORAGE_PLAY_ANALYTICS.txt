SONORA 3.5 ADMIN UPDATE

Included:
- Music catalogue search across title, artist, album and genre; existing Edit/Delete actions remain available.
- Styled audio file picker with drag-and-drop.
- Album suggestions from existing catalogue albums; type a new album name manually when tags/online lookup cannot identify it. Reuse the exact album name to group tracks in the same album.
- R2 bucket storage snapshot and estimated Standard storage charge. Estimate uses Cloudflare public pricing: 10 GB-month included, then $0.015 per GB-month. It is not an invoice and excludes Class A/B request charges and any other account products.
- Playback analytics KPI: play event count and total listening time. Logged for signed-in listeners only.

REQUIRED DATABASE STEP:
Run sql/sonora-3-5-play-analytics.sql in Supabase SQL Editor before deploying. Existing tracks and R2 files are not modified.

DEPLOY:
1. Publish frontend files to GitHub Pages.
2. cd cloudflare/worker && npx wrangler deploy
3. Run the SQL migration first, then sign in as admin and refresh the dashboard.

R2 STORAGE ESTIMATE NOTE:
The dashboard scans up to 50,000 R2 objects per refresh. If it reports the scan is truncated, its byte total and estimate are a lower bound. Cloudflare billing uses average daily stored bytes (GB-month), so the dashboard's instantaneous estimate is approximate.
