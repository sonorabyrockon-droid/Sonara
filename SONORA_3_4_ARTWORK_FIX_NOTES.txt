SONORA 3.4 — ALBUM ARTWORK DELIVERY FIX

- R2 cover uploads now use an image extension matching the detected MIME type.
- The public /stream/ route now serves JPEG, PNG, WEBP and GIF objects as well as audio.
- Legacy extensionless objects under covers/ are also accepted when their stored R2 content type is image/*.
- Homepage catalogue already reads tracks.cover_url; newly uploaded artwork can now load through the public Worker URL.

Deploy the updated Worker from cloudflare/worker with: npx wrangler deploy
Then upload a new test MP3 with embedded artwork and refresh the homepage.
Existing tracks with a cover_url should also start displaying if their R2 object exists and has image content-type metadata.
