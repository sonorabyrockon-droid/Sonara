Required deployment order
-------------------------
1. Back up the existing Supabase database.
2. Run sql/sonora-3-20-music-description.sql in Supabase SQL Editor.
3. Publish the repository contents from this package to GitHub Pages.
4. Deploy the Worker from cloudflare/worker with `npx wrangler deploy`.
5. Verify an Admin description edit updates the catalogue without a hard refresh.
6. Test a batch with valid files, a duplicate title/artist, and an unsupported file.

Existing limits are unchanged: 100 MB per audio file and 12 uploads per
administrator per hour. Multi-file uploads are sequential and report per-file
success/failure. Only upload recordings you own or are licensed to distribute.
