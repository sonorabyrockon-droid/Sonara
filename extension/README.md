# SONORA Chrome extension (desktop)

1. Open `chrome://extensions` in desktop Google Chrome.
2. Turn on **Developer mode**.
3. Choose **Load unpacked** and select this `extension` folder.
4. Pin SONORA from the Extensions menu if desired.

This lightweight extension opens the official SONORA web app in a new tab. It does not store passwords or access listening data.

**Phones:** Chrome on Android generally does not support desktop Chrome extensions. Use the SONORA PWA instead: open the website in Chrome and choose **Install app** or **Add to Home screen**. On iPhone/iPad, open the site in Safari and choose **Share → Add to Home Screen**.
