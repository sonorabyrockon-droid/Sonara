SONORA · Chrome extension

This is a lightweight desktop Chrome launcher for the SONORA music app.

  1. Download the SONORA project ZIP from the repository.
  2. Extract it on your computer.
  3. Open chrome://extensions in desktop Chrome.
  4. Enable Developer mode, select Load unpacked, then choose the extension folder.

On phones, install the PWA from the SONORA website instead. Desktop Chrome extensions are not supported by standard Chrome for Android.
